# Misi Editor Cilik — The Ultimate Bahasa Melayu Run

Aplikasi DLO Bahasa Melayu berkonsepkan endless runner/gamifikasi.

## Cara jalankan
1. Muat turun atau clone repositori ini.
2. Buka `index.html` menggunakan pelayar web.
3. Untuk menerbitkan melalui GitHub Pages:
   - Cipta repositori GitHub.
   - Muat naik `index.html` dan `README.md`.
   - Buka **Settings → Pages**.
   - Pilih **Deploy from a branch**, pilih `main` dan folder `/ (root)`.
   - Simpan dan tunggu pautan GitHub Pages diterbitkan.

## Kandungan
- Pendaftaran nama dan kelas.
- Dashboard, syiling, XP dan kemajuan misi.
- Misi 1: Kenali penulisan, larian 3 lorong (elak halangan/kutip syiling) dan kuiz.
- Misi 2: Susun perkataan dan bina draf.
- Misi 3: Detektif kesalahan bahasa.
- Misi 4: Bengkel penyuntingan dengan simulasi pembantu AI.
- Misi 5: Penulisan akhir, kuiz, refleksi dan sijil.
- Penyimpanan setempat menggunakan localStorage.

## Nota teknikal
Ini ialah prototaip front-end tanpa pangkalan data atau akaun murid. Kemajuan disimpan dalam pelayar/peranti yang digunakan. Pembantu AI ialah simulasi berasaskan contoh pembetulan; ia tidak menghantar teks murid kepada perkhidmatan AI luar. Jangan masukkan maklumat peribadi sensitif.
